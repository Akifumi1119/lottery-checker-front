## 機能仕様

### F-01 宝くじ種類選択

以下の7種類からセレクトボックスで選択する。種類を切り替えると回一覧・入力内容・照合結果がリセットされる。

| キー | 表示名 |
|------|--------|
| `jumbo` | ジャンボ宝くじ |
| `zenkoku` | 全国通常宝くじ |
| `tokyo` | 東京都宝くじ |
| `kct` | 関東・中部・東北自治宝くじ |
| `kinki` | 近畿宝くじ |
| `nishinihon` | 西日本宝くじ |
| `chiiki` | 地域医療等振興自治宝くじ |

### F-02 回一覧取得

- 種類選択時・アプリ起動時にAPIから回一覧と各回の当選番号を取得する
- データ取得中はローディングオーバーレイを全画面表示する

### F-03 回選択

- セレクトボックスから照合したい回（例: 第123回 グリーンジャンボ）を選択する
- 回を選択すると照合モード切替と入力フォームが表示される

### F-04 照合モード切替

トグルボタンで2つのモードを切り替える。切り替え時に照合結果はリセットされる。

| モード | 説明 |
|--------|------|
| **単番** | 1枚または複数枚の宝くじを個別に指定して照合する |
| **連番** | 開始番号と枚数を指定し、連番の宝くじをまとめて照合する |

### F-05 組入力

- テキスト入力フィールドに組番号を入力する
- 全角数字は自動的に半角数字に変換される
- 数字以外の文字は入力不可

### F-06 番号入力

- 6桁の宝くじ番号を1桁ずつ6つの入力フィールドに入力する
- 1桁入力すると自動的に次のフィールドにフォーカスが移動する
- Backspace で前のフィールドに戻る
- 連続した数字のペーストに対応（例: `123456` をペーストすると各桁に分配される）
- 全角数字は自動的に半角数字に変換される
- 数字以外の文字は入力不可

### F-07 単番モード：複数枚追加

- 「+ 追加」ボタンをクリックするとチケット入力欄（組 + 番号）を追加できる
- 2枚目以降には「○枚目」ラベルと「削除」ボタンが表示される
- 枚数の上限なし

### F-08 連番モード：枚数指定

- 開始番号と枚数（2〜100枚、デフォルト10枚）を指定する
- 照合時に開始番号から連番で全枚数を一括チェックする

### F-09 当選照合と結果表示

| 条件 | 表示形式 |
|------|---------|
| 単番・1枚 | 「○組 ○○○○○○番」の下に等級と金額を大きく表示 |
| 単番・複数枚 | 当選枚数のサマリー + 全枚数の一覧リスト |
| 連番 | 当選枚数のサマリー + 全番号の一覧リスト |
| 当選チケット | 赤字・太字でハイライト |
| ハズレチケット | グレーで表示 |

## 当選判定ロジック

APIから取得した `prizes` 配列を順番に走査し、最初に一致した賞を返す。

### 判定ルール（優先順位順）

| 優先度 | 賞 | 判定条件 |
|--------|-----|---------|
| 1 | 1等の前後賞 | 入力番号が「1等番号 ± 1」と一致 |
| 2 | 1等の組違い賞 | 入力番号が1等番号と一致、かつ入力組が1等の組と異なる |
| 3 | 下○ケタ | 入力番号の末尾○桁が当選番号の末尾○桁と一致（`組下` を含むルールは除く） |
| 4 | 各組共通 | 組を問わず入力番号が当選番号と一致 |
| 5 | ○組 | 入力組と当選組が一致、かつ入力番号が当選番号と一致 |
| 6 | 組下○ケタ○組 | 入力組の末尾○桁が指定の組末尾と一致、かつ入力番号が当選番号と一致 |
| — | ハズレ | 上記いずれにも一致しない |

## API仕様

### エンドポイント一覧

| 種類 | エンドポイント |
|------|---------------|
| ジャンボ宝くじ | `GET {VITE_API_URL}/api/lotteries` |
| 全国通常宝くじ | `GET {VITE_API_URL}/api/lotteries/zenkoku` |
| 東京都宝くじ | `GET {VITE_API_URL}/api/lotteries/tokyo` |
| 関東・中部・東北自治宝くじ | `GET {VITE_API_URL}/api/lotteries/kct` |
| 近畿宝くじ | `GET {VITE_API_URL}/api/lotteries/kinki` |
| 西日本宝くじ | `GET {VITE_API_URL}/api/lotteries/nishinihon` |
| 地域医療等振興自治宝くじ | `GET {VITE_API_URL}/api/lotteries/chiiki` |

### レスポンス型

```typescript
interface Lottery {
  round: string;       // 回号
  name: string;        // くじの名称
  draw_date: string;   // 抽選日
  prizes: Prize[];
}

interface Prize {
  rank: string;   // 等級名称（例: "1等", "1等の前後賞"）
  number: string; // 当選番号（6桁）
  amount: string; // 当選金額
  rule: string;   // 判定ルール文字列
}
```

**レスポンス例**

```json
[
  {
    "round": "123",
    "name": "グリーンジャンボ",
    "draw_date": "2025-03-14",
    "prizes": [
      { "rank": "1等",         "number": "123456", "amount": "3億円",  "rule": "1組123456番" },
      { "rank": "1等の前後賞", "number": "",       "amount": "1億円",  "rule": "1組前後賞"   },
      { "rank": "1等の組違い賞","number": "123456", "amount": "10万円", "rule": "組違い賞"    },
      { "rank": "3等",         "number": "456",    "amount": "1万円",  "rule": "下3ケタ"     }
    ]
  }
]
```
